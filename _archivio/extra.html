installare

Claude Code

# Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex
# macOS / Linux
curl -fsSL https://claude.ai/install.sh | bash

Codex

# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
# macOS / Linux
curl -fsSL https://chatgpt.com/codex/install.sh | sh
# oppure, con Node.js
npm install -g @openai/codex

Chiudete e riaprite il terminale; claude --version / codex --version per controllare.

Poi: tasto destro sulla cartella → Apri nel terminale → claude o codex. Da lì, italiano.
